# MOYAMOVA 1.5

**MOYAMOVA** — офлайн-тренажёр для изучения иностранных языков на карточках.  
Работает прямо в браузере, без регистрации, без обязательного бэкенда.

- 📱 Оптимизировано под мобильные устройства (портретный режим)
- 📴 Работает офлайн через PWA + Service Worker
- 🧠 Движок тренировки: звёзды + сеты + режимы (Auto / Reverse / Focus)
- 📊 Статистика прогресса и активности (тепловая карта)
- 💾 Резервные копии: экспорт / импорт прогресса одним файлом
- 🤖 Поддержка Android TWA (assetlinks)

---

## 🚀 Что умеет приложение

### 🎴 Словари и деки

- Готовые словари по языкам:
  - **DE** (немецкий) — базовые деки + отдельные тренеры
  - **EN** (английский)
  - **Lernpunkt** — отдельная учебная ветка/деки (может быть скрыта через visibility-gate)
- Раздел **«Словари»**:
  - список доступных дек;
  - прогресс по каждой деке (сколько выучено);
  - переключение между языками через флаги;
  - запуск тренировки по выбранной деке.

Каждое слово можно:
- выучить через тренажёр;
- добавить в избранное;
- при ошибке оно автоматически попадает в «Мои ошибки».

---

### ⭐ Тренажёр и прогресс

- Алгоритм на основе **звёздочек**:
  - у каждого слова есть уровень освоения от `0` до `starsMax`;
  - тренажёр повышает или понижает уровень в зависимости от ответа;
  - слово считается *выученным*, когда достигает максимального уровня.
- Сеты:
  - тренировка идёт сетами;
  - есть круговое продвижение по сетам;
  - (опционально) автопереход по сетам.
- Доп. логика:
  - «cooldown» — защита от бессмысленного фарма звёзд при сериях ошибок;
  - отдельная работа с сериями ошибок по слову.

---

### 🔁 Режимы тренировки (burger → настройки)

- **Авто (Auto step)** — автопереход по сетам (можно отключить → ручной режим).
- **Обратный перевод (Reverse)** — тренировка в обратном направлении (симметрично для режимов и виртуальных дек).
- **Концентрация (Focus)**:
  - Сеты / Контекст — можно скрывать/показывать части UI для фокуса.
- **Озвучка (TTS)**:
  - отдельные режимы для слов и примеров;
  - язык/голос выбирается по активной деке.

---

### 🧩 Фильтры (темы/ограничения)

- Шторка фильтров работает по сценарию **draft → Apply** (без live-apply и без rollback).
- Есть guard против «усыхания» набора: тренер гарантирует достаточное число вариантов.
- Для виртуальных дек `favorites:*` / `mistakes:*` фильтры **не применяются** (и в UI это явно показано).

---

### 📚 Избранное и Мои ошибки

- **Избранное**:
  - отдельный экран со словами, которые пользователь отметил вручную;
  - удобно использовать как «личный словарик».
- **Мои ошибки**:
  - виртуальная дека, собирающая слова, по которым были неправильные ответы;
  - помогает целенаправленно отработать слабые места;
  - запускается как отдельная тренировка.

---

### 📚 Дополнительные тренеры

#### 🧾 Тренер артиклей (DE)
Отдельная подсистема с собственной логикой и хранилищами:
- прогресс/статистика артиклей;
- избранное/ошибки артиклей;
- автопереход по сетам работает симметрично word-trainer;
- в режимах mistakes:* избранное блокируется (с тостом).

#### 🔤 Тренер предлогов (EN/DE)
Отдельный тренер на датасете паттернов:
- запуск только из строки предлогов;
- отдельный ключ тренера (`*_prepositions_trainer`) во избежание конфликтов;
- интегрирован в общую навигацию и режимы.

---

### 📊 Статистика изучения

Экран **«Статистика»** показывает прогресс:

- Переключение между языками через флаги (как в «Словарях»).
- Для каждого языка:
  - общее количество слов в деках;
  - сколько из них выучено;
  - сколько дек начато и завершено;
  - распределение по частям речи (кольцевые диаграммы).

Дополнительно:
- блок **«Активность»** (точки по дням);
- 4 уровня активности;
- максимум активности достигается при **3+ завершённых сетах за день**.

---

### 🎨 Интерфейс

- Светлая и тёмная тема (сохранение в настройках).
- Язык интерфейса: **RU / UK** (через i18n).
- Режим сложности: обычный / сложный.

---

### 💾 Резервное копирование

- Раздел **«Резервное копирование»** в боковом меню:
  - **Экспорт** — скачивание файла с текущим состоянием;
  - **Импорт** — загрузка ранее сохранённого файла и восстановление состояния.
- В бэкап входят:
  - прогресс по звёздам и служебные поля тренажёра;
  - прогресс сетов;
  - избранное и ошибки (включая виртуальные деки);
  - настройки темы/языка/режимов.

## 🧩 Архитектура проекта

Проект построен без крупных фреймворков — **чистый JavaScript**, модульная структура и разбиение по зонам ответственности.

Основные слои:

- `app.shell.view.js`, `app.shell.logic.js` — UI-каркас, навигация, burger, футер.
- `app.core.js` — базовый объект `App`, утилиты, версия, сохранение состояния.
- `dicts/` — данные дек (`deck.*.js`) и датасеты тренеров.
- `app.decks.js` — работа с деками, язык/флаги/имена, сеты.
- `app.decks.bridge.js` — виртуальные деки и спец-ключи (favorites/mistakes, prepositions trainer).
- `app.trainer.js` — логика word-trainer (звёзды, выбор слов, сеты, reverse/autostep).
- `app.favorites.js`, `app.mistakes.js` — логика избранного/ошибок.
- `app.filters.js` — фильтры и построение trainable-набора.
- `articles.*` — подсистема тренера артиклей.
- `prepositions.*` — подсистема тренера предлогов.
- `ui.*.js` — UI-утилиты и подсистемы (stats/progress/sets/state/notify и др.).
- `view.*.js` — экраны:
  - `view.dicts.js`, `view.favorites.js`, `view.mistakes.js`, `view.stats.js`, `view.guide.js`
  - `home.js` — главный контроллер/диспетчер экранов и тренеров.
- `app.backup.js` — экспорт/импорт состояния.
- `sw.js`, `manifest.webmanifest` — PWA/офлайн.
